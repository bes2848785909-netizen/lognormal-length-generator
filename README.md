#严格满足均值与变异系数的路段长度生成器

> 专为交通仿真（SUMO/Vissim）设计 | **严格保证 `E[X]=N` 且 `CV=c`** | 附物理边界校正
*生成 10,000 个路段：目标均值=400m, CV=0.82 → 实际均值=400.000m, CV=0.815*

##为什么需要它？

| 常见方法                | 能否保证 `E[X]=N` | 是否天然正数 | 边界截断后均值是否偏移 |
|-------------------------|-------------------|--------------|------------------------|
| 正态分布 `N(N, cN)`      | 0 (截断后失效)     | 0            | 1 (但需复杂修正)        |
| **本工具**              | 1                 | 1            | 0 (通过缩放自动修正)     |

> **关键痛点**：直接用 `np.random.lognormal(mean=np.log(N))` 会导致 **期望 ≠ N**（[数学推导](#原理说明)）

##使用案例
```python
from lognormal_generator import generate_lengths

# 生成10,000个北京典型路网路段（均值400m，CV=0.82）
road_lengths = generate_lengths(
    mean=400,   # 期望长度（米）
    cv=0.82,    # 变异系数（北京路网实测值）
    size=10000,
    bounds=(50, 2000)  # 物理边界：最小50m，最大2000m
)
